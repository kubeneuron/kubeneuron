# CLA signatures

This branch holds only the record of contributors who agreed to the
[KubeNeuron Contributor License Agreement](https://github.com/kubeneuron/kubeneuron/blob/main/CLA.md).

`signatures/cla.json` is written by the `CLA` workflow on `main`
(`.github/workflows/cla.yaml`). Do not merge this branch into any other
branch, and do not edit or delete it by hand: it is the proof of agreement.
Force pushes and deletion are blocked by a repository ruleset.
